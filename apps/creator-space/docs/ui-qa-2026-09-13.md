# Creator Space UI QA — 2026-09-13

## Scope and migration impact

Only `apps/creator-space` changes. No MINSEC portfolio sources, Supabase schema,
RLS policies, OAuth redirects, or staff permissions changed. Existing free-text
profile tags remain supported. Tag suggestions store the same string arrays.
Rollback: revert this UI commit and rebuild/redeploy the Worker. No data rollback
is required. Original Worker version: `0dc1dd8c-3c97-4d2e-a60d-0c9b88e9169b`.

## Changes

- Separate board list, post detail, and `/space/write/` composer. Legacy `#write`
  links forward to the composer. List only fetches summaries, without fetching
  every post body, comments, and attachment list.
- Notice/secret filters and title/author search explicitly operate on loaded
  rows; loading more extends the searchable set. Category purpose descriptions.
- Separate account login, profile, contacts, and Creator application pages.
- Korean suggested tags, selected chips, custom tags, duplicate/count guards.
- Busy buttons, inline saved timestamp, unsaved-change warning, visible action
  feedback, cross-page save/delete confirmation. Korean common error messages.
- Compact horizontal comment actions and a cancel action for comment editing.
- Image selection preview and inline post images. Posted images are downloaded
  from the private Storage bucket under the current user's RLS permissions and
  displayed using temporary object URLs. SVG is not previewed. Documents remain
  downloads. Image decoding failures retain the download option.

  profile display; only that profile's owner sees its edit button.

  suggestions and relevant controls. Publication requires project role/event
  start date and meaningful recruitment/event details. Hidden existing optional
